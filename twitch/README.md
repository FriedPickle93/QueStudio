# XQUESEX Twitch kit

Banner, profile photo, and channel panels based on the purple lightning artwork. Open `index.html` for a preview.

## Files

| File | Twitch slot | Size |
| --- | --- | --- |
| `avatar.jpg` | Profile photo | 800 × 800 |
| `profile-banner.jpg` | Profile banner | 1200 × 480 |
| `offline-banner.jpg` | Offline screen | 1920 × 1080 |
| `panels/*.jpg` | About panels | 1024 × 1024 |

## Panels

Upload them in this order:

1. About
2. Schedule
3. Socials
4. Discord
5. Subscribe
6. Donate
7. Rules
8. Specs

The schedule panel reads **LIVE NIGHTS / SEE DESCRIPTION** so the real days and times can live in the panel text. Social icons are generic (camera, play, heart, link) so each one can point at a real profile.

## Where to upload

- Profile photo and profile banner: Creator Dashboard → Settings → Channel → Brand
- Offline banner: Creator Dashboard → Settings → Stream, or the offline image in Stream Manager
- Panels: channel page → Edit panels → Add a panel → Image, then paste the link you want that panel to open
